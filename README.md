# wiener-linien-epaper
Real-time Wiener Linien departure monitor for Raspberry Pi with a Waveshare 2.9″ e-Paper V2 display (epd2in9_V2), featuring departure countdowns, service alerts, and offline caching.

The 296×128 monochrome layout uses FreeSans Bold for destinations and FreeMono Bold for countdowns (provided by Raspberry Pi OS's `fonts-freefont-ttf` package). Icons are drawn directly in pixels; service disruptions appear in a two-line inverted alert strip.
